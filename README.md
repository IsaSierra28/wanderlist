# Wanderlist

GitHub: https://github.com/IsaSierra28/wanderlist

A React Native (Expo) app to keep a list of places you want to visit. Add a place with a name, notes and a category, and see your list sorted from A to Z.

## Run it

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app, then press `a` to open it on the Android emulator

   ```bash
   npx expo start
   ```
